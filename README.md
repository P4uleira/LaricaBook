# 🍽️ **LaricaBook – Sistema de Receitas com Flask, Cassandra e Docker**

## 📌 **Descrição Geral**

**LaricaBook** é um sistema desenvolvido para armazenar, organizar e consultar receitas culinárias de forma rápida e escalável.
O projeto utiliza:

* **Python + Flask** para construir a API web
* **Apache Cassandra** como banco NoSQL distribuído
* **Docker e Docker Compose** para gerenciar todo o ambiente da aplicação e do banco

O objetivo é demonstrar o uso de tecnologias modernas para criar uma aplicação leve, modular e altamente escalável.

---

## 🎯 **Objetivo do Sistema**

* Permitir o cadastro e gerenciamento de receitas culinárias.
* Garantir alta disponibilidade utilizando **Cassandra**.
* Demonstrar arquitetura separada e facilmente escalável usando **Docker**.
* Criar uma API REST simples, organizada e documentada.

---

# 🔧 **Tecnologias Utilizadas**

| Tecnologia           | Função                            |
| -------------------- | --------------------------------- |
| **Python 3**         | Linguagem principal               |
| **Flask**            | Framework para API REST           |
| **Apache Cassandra** | Banco NoSQL distribuído           |
| **Docker**           | Container da aplicação            |
| **Docker Compose**   | Orquestração da aplicação + banco |
| **CQL**              | Linguagem do Cassandra            |
| **Requests/JSON**    | Entrada e saída da API            |
